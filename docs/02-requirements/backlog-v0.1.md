\# Backlog v0.1 — CondoFlow PA-04



\## Historias de usuario



| ID | Prioridad | Historia de usuario | Criterio de aceptación inicial |

|---|---|---|---|

| HU-01 | P0 | Como administrador, quiero gestionar las unidades del condominio para mantener actualizada la información de cada unidad. | Una unidad puede registrarse y consultarse con su información básica. |

| HU-02 | P0 | Como administrador, quiero registrar personas y asociarlas a una unidad mediante una residencia para mantener actualizado quién habita cada unidad. | Una persona puede asociarse a una unidad indicando la vigencia de la residencia. |

| HU-03 | P0 | Como residente, quiero solicitar una reserva de un área común para poder utilizarla en un horario determinado. | Una solicitud de reserva debe indicar el área y el período de uso. |

| HU-04 | P0 | Como personal de seguridad, quiero registrar las visitas asociándolas a una unidad de destino para controlar los ingresos al condominio. | Una visita debe quedar asociada a una unidad y registrar su vigencia prevista. |

| HU-05 | P1 | Como administrador, quiero registrar y dar seguimiento a incidencias para conocer los problemas que requieren atención dentro del condominio. | Una incidencia puede registrarse y consultarse para conocer su situación. |

| HU-06 | P1 | Como administrador, quiero registrar tareas de mantenimiento para organizar los trabajos que deben realizarse en el condominio. | Una tarea de mantenimiento puede registrarse y consultarse con su información principal. |

| HU-07 | P1 | Como administrador, quiero publicar comunicados para informar a los residentes sobre información relevante del condominio. | Un comunicado puede registrarse y quedar disponible para su consulta. |

| HU-08 | P2 | Como usuario, quiero recibir notificaciones sobre eventos relevantes del condominio para mantenerme informado. | El sistema debe generar una notificación asociada a un evento relevante. |



\## Priorización



\### P0 — Núcleo del MVP



\- HU-01 Gestión de unidades.

\- HU-02 Gestión de personas y residencias.

\- HU-03 Reservas de áreas comunes.

\- HU-04 Control de visitas.



\### P1 — Operación complementaria



\- HU-05 Gestión de incidencias.

\- HU-06 Gestión de mantenimiento.

\- HU-07 Gestión de comunicados.



\### P2 — Complemento



\- HU-08 Notificaciones.



\## Observaciones



Las historias representan necesidades de actores del dominio y no tareas técnicas de implementación.



La prioridad P0 representa las capacidades necesarias para sostener el núcleo operativo inicial del proyecto.
