\# Glosario v0.1 — CondoFlow



| Término | Significado inicial |

|---|---|

| Unidad | Espacio o propiedad individual que forma parte del condominio. |

| Residente | Persona que habita o utiliza una unidad del condominio. |

| Residencia | Registro que relaciona a una persona con una unidad del condominio. |

| Área común | Espacio compartido del condominio que puede estar sujeto a reglas de uso y reserva. |

| Reserva | Registro de la solicitud de uso de un área común durante un período determinado. |

| Incidencia | Situación o problema ocurrido dentro del condominio que debe ser registrado y atendido. |

| Visita | Persona externa autorizada para ingresar al condominio durante un período determinado. |

| Comunicado | Información o aviso que la administración publica para los residentes. |

| Mantenimiento | Actividad destinada a conservar o reparar elementos o espacios del condominio. |

| Tarea de mantenimiento | Trabajo específico que debe realizarse para atender una necesidad de mantenimiento. |

| Notificación | Aviso enviado a un usuario para informarle sobre un evento o cambio relevante. |

| Administración | Gestión de las actividades operativas y de información del condominio. |

| Condominio | Conjunto de unidades, residentes y espacios comunes administrados mediante el sistema. |

| Unidad habitacional | Espacio individual del condominio asociado a residentes o propietarios. |

| Panel operativo | Vista que permite consultar información relevante sobre el estado de la operación del condominio. |
